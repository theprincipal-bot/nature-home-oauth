Nature Home Calendar Sync

概要 / Overview

Nature Home Calendar Sync は、開発者本人が個人で使うカレンダー同期ツールです。開発者自身の iCloud カレンダーと Google カレンダーの予定を、相互に同期します。一般には配布していません。

Nature Home Calendar Sync is a personal tool used only by its developer. It synchronizes the developer's own iCloud Calendar and Google Calendar events with each other. It is not distributed to the public.

機能 / What the app does

  • iCloud カレンダーで作成・変更・削除した予定を、Google カレンダー側の対応するカレンダーに反映する。
  • Google カレンダー側で作成・変更・削除した予定を、iCloud カレンダーに反映する。
  • Google Calendar API を使い、このアプリが作成したカレンダーの予定の閲覧・作成・変更・削除だけを行う。
  • Copies events created, changed or deleted in iCloud Calendar to the matching calendars in Google Calendar.
  • Copies events created, changed or deleted in Google Calendar back to iCloud Calendar.
  • Uses the Google Calendar API only to view, create, change and delete events on calendars created by this app.
