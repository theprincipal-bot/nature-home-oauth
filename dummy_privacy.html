プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-11-09

← Nature Home Calendar Sync

1. 取得する情報 / Data accessed

Nature Home Calendar Sync は、利用者(開発者本人)の Google カレンダーのうち、このアプリが作成したカレンダーの予定(題名、日時、場所、メモ、参加者、公開範囲)にアクセスします。

The app accesses events (title, time, location, notes, attendees, visibility) on the Google calendars that this app creates in the user's own Google account. The user is the developer.

2. 利用目的 / How the data is used

取得した情報は、iCloud カレンダーと Google カレンダーの間で予定を同期する目的だけに使います。広告、分析、第三者への提供には使いません。

The data is used only to synchronize events between iCloud Calendar and Google Calendar. It is not used for advertising or analytics, and it is not provided to third parties.

3. 保存と保護 / Storage and protection

同期に必要な情報は、開発者本人が管理する AWS のアカウント(AWS Lambda と Amazon DynamoDB)に保存します。保存時に暗号化され、アクセスは開発者本人に限られます。削除された予定の記録は90日、ログは短期間で自動的に削除されます。

Information needed for synchronization is stored in the developer's own AWS account (AWS Lambda and Amazon DynamoDB), encrypted at rest and accessible only to the developer. Records of deleted events are removed automatically after 90 days, and logs after a short period.

4. 共有しません / No sharing

Google ユーザーのデータを、第三者に販売、共有、移転することはありません。人が内容を読むこともありません。

The app does not sell, share or transfer Google user data to third parties, and no human reads the data.

5. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

Nature Home Calendar Sync による、Google API から受け取った情報の使用と移転は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

Nature Home Calendar Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. アクセスの取り消し / Revoking access

Google アカウントの「サードパーティのアクセス」(アカウントの管理画面)から、いつでもこのアプリのアクセスを取り消せます。

Access can be revoked at any time from the third-party access settings of the Google Account.
